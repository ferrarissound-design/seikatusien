# Life Partner かんたん操作マニュアル

## はじめに
- Safari でアプリのページを開き、「共有ボタン →ホーム画面に追加」をしてください。
- 追加したら、いつも **ホーム画面のアイコン** から開いてください（Safari とホーム画面アプリでは保存場所が別です）。
- 最初の設定はすべて「スキップ」できます。あとから「設定」で変えられます。

## 画面の下のメニュー
| ボタン | できること |
|---|---|
| ホーム | 今日の情報をまとめて見る。チェック・タスク完了・支出の記録もここから |
| 忘れ物 | 持ち物リスト |
| タスク | やること |
| お金 | 今日使える金額・記録 |
| 設定 | バックアップ・通知・表示など |

## 忘れ物チェック
1. 「忘れ物」→「リストを作る」→ 仕事・通院などを選ぶ
2. 持ち物を押すとチェックが付きます（すぐ保存されます）
3. 全部チェックすると「ぜんぶ確認できました」と出ます
4. 毎朝4時に自動でチェックが外れます（時刻は右上の⚙で変更）。前の日の記録は「履歴」で見られます
- 持ち物の名前を変える・消す：右の鉛筆ボタン
- 順番を変える：「並び替え」→ ▲▼

## タスク（やること）
1. 「追加」→ やることを書く →「今日／明日／日付／いつでも」を選ぶ →「追加」
2. 終わったら左の丸を押す
- 大きなことは「小さなステップに分ける」欄に1行ずつ書くと、1つずつ進められます
- 終わらなかったタスクは、次の日に「繰り越し」として出てきます。責める表示はしません
- 「集中モード」：いま取り組む1つだけを大きく表示します。「あとで取り組む」で次へ

## お金
### 最初に
「お金」→「残高・予算を登録する」で、わかるものだけ入れます。
- **いまの残高**：給料日までに使えるお金の合計
- **給料日**：毎月の給料日
- **予算**：給料日までに使ってよい金額（家賃などの固定費は別）
- **確保したい貯金**：給料日まで手をつけたくない金額

### 毎日
- 「支出を記録」→ 金額を入れる → カテゴリー（食費など）を押す。これで記録完了です
- 「今日使える金額」は、残りのお金を給料日までの日数で割った **目安** です
- 計算の方法は「計算の内訳」で確認できます

### 固定費
「お金 → 固定費」に家賃・スマホ代などを登録すると、自動で差し引いて計算します。払ったら「支払った」を押してください。

### 足りなくなりそうなとき
0円や「足りない見込み」と表示されたら、「調整のヒント」を見てください。あわてなくて大丈夫です。

## 体重（使う人だけ）
- 「設定 → 使う機能」で「体重」をオンにすると、ホームに体重のカードが出ます
- 「今日の体重を記録」→ 数字（例：65.45）を入れて「記録する」
- 「記録を見る」で、これまでの記録と30日・90日の推移を見られます。「表で見る」で数字の一覧も見られます
- 目標や「多い・少ない」の判定はしません。自分のペースで記録してください

## 間違えたとき
- 消してしまった → 画面の下に出る「元に戻す」を押す
- 記録を直したい → その記録を押して編集

## データを守る
- **クラウドバックアップ**：「設定 → 保存と同期」でアカウントを作ると、機種変更やアプリの入れ直しでも戻せます
- **ファイルに保存**：「設定 → バックアップ → 書き出す」→「ファイルに保存」
- 戻すとき：「設定 → バックアップ → ファイルを選ぶ」→ 内容を確認して「復元する」。いまのデータは消えません

## 通知
「設定 → 通知・リマインダー」で時刻を決めると、その時刻を過ぎたあとにアプリを開いたとき「お知らせ」が出ます。
端末の通知を使うには「端末の通知を許可する」を押してください（iPhone はホーム画面に追加してから）。

## 困ったとき
- 表示がおかしい：「設定 → データの削除・アプリの更新 → キャッシュを消して読み込み直す」（記録は消えません）
- 「同期できませんでした」：記録は端末に保存されています。電波の良い場所で「今すぐ同期」

このアプリは日常生活を補助するためのもので、医療や診断を目的としたものではありません。
